# Learning plan

Suggested sequence; mark a topic complete only after you can explain and run the exercise.

- [ ] Git basics: status, diff, add, commit, push and a useful README.
- [ ] Tensor shapes, broadcasting, indexing and device placement.
- [ ] Autograd, gradients, loss functions and optimizers.
- [ ] Dataset, DataLoader and separate training/validation/test data.
- [ ] A complete small classification loop with held-out metrics.
- [ ] Embeddings, positional encoding, attention and masks.
- [ ] Trace the existing Transformer implementation and fix problems found through execution.
- [ ] Vision Transformer: patches, embeddings and classification.
- [ ] Vision-language models: image encoder, projector and language model.
- [ ] Read one grounding paper and explain its inputs, method and evaluation.
- [ ] Run one feasible research baseline and record environment, command and results.

Progress evidence matters more than consecutive-day counts. Write a short weekly note covering what runs, what you can explain, blockers and the next concrete task.
